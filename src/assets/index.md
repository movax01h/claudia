# Assets Directory

This directory contains static assets used throughout the Claudia application including graphics, audio files, and CSS effect libraries.

## Files

**react.svg** - React logo used in development or branding contexts

**shimmer.css** - CSS animation library providing shimmer and glowing effects for interactive UI elements, enhancing the visual appeal of buttons, cards, and hover states

## Subdirectories

**nfo/** - Contains assets specifically for the NFO (Network File Object) credits system that provides information about the application and development team

### nfo/ Contents

**asterisk-logo.png** - Logo image for Asterisk, the development team/organization behind Claudia

**claudia-nfo.ogg** - Audio file used in the NFO credits sequence, likely containing background music or sound effects for the credits display

## Usage Context

These assets support the application's visual identity and user experience enhancements. The shimmer effects provide modern, interactive feedback for user actions, while the NFO assets create an engaging credits/about experience that acknowledges the development team and provides application information in a visually appealing format.

The assets are referenced throughout the component tree, particularly in the main App component for NFO credits functionality and in various UI components that utilize shimmer effects for enhanced interactivity.
