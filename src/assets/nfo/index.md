# NFO Assets Directory

This directory contains assets specifically for the NFO (Network File Object) credits system that provides information about Claudia and its development team.

## Files

**asterisk-logo.png** - Official logo image for Asterisk, the development team/organization behind Claudia. Used in the credits display to provide visual branding and acknowledgment of the creators.

**claudia-nfo.ogg** - Audio file used during the NFO credits sequence. Contains background music or sound effects that enhance the credits presentation experience, creating an engaging multimedia display when users access the application information.

## Purpose

The NFO credits system follows a retro computing tradition where software would include credits files (originally "Network File Object" or "iNFO" files) that provided information about the creators, often with ASCII art and music. This modern implementation maintains that spirit while providing an engaging way to showcase the development team and application details.

These assets work together with the NFOCredits component to create a cohesive credits experience that users can access from the main application interface, combining visual branding with audio enhancement for a memorable presentation of the development team's work.
